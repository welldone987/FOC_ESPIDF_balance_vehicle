数据范围与保存方式

此处显示固件 BLE DIAG 摘要和错误事件，不是串口日志镜像。当前无线包不含实测值、阈值、源码行号或完整控制快照；原始码 0 也不表示无故障，应用层检查可能没有 SDK 原始码。通道含义由检测点决定。

固件先重放首故障，再重放仍在 RAM 中的历史；页面按事件序号去重。首故障之外的设备事件最多保留 16 条，历史可能被覆盖。页面每次连接最多保留 256 条事件及独立首故障，最多保留 8 次连接，断开后仍可导出；刷新或关闭页面前请导出。接收时间来自电脑，不是设备故障时间。

启动完成只代表 BOOT 检查通过；采样序号持续变化才说明控制循环在推进。此处不能读取 Flash Core dump，也不能证明闭环稳定或电机实际输出。
